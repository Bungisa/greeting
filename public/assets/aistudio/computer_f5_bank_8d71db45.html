Activity 8.28: Building a task management web application with PHP, PDO, and MySQL

Aim: To develop proficiency in PHP and PDO for performing CRUD operations on a MySQL database while creating a functional web-based task management application.

Instructions:

  1. Step 1: Database setup:
    1. Create a MySQL database named task_manager.
    2. Within task_manager, create a table named tasks with fields: id (INT, Primary Key, Auto Increment), task_name (VARCHAR(255)), and is_completed (BOOLEAN or TINYINT defaulting to 0).
  2. Step 2: PHP application setup:
    1. Create index.php for listing tasks.
    2. Create add_task.php for adding new tasks.
    3. Create update_task.php for updating task completion status.
    4. Create delete_task.php for deleting tasks.
  3. Step 3: CRUD Operations:
    1. Create (Add new task): Implement a form in add_task.php to insert new tasks into the tasks table using PDO.
    2. Read (List tasks): Query all tasks in index.php and display them in a list format showing task names and completion status. Include functionality for "Mark as Completed/Not Completed", "Edit", and "Delete".
    3. Update (Mark task as completed/not completed): Develop logic in update_task.php to toggle the completion status of tasks based on user interaction.
    4. Delete (Remove a Task): Implement functionality in delete_task.php to delete tasks from the tasks table.
  4. Step 4: Testing:
    1. Test adding new tasks through add_task.php.
    2. Verify the list of tasks and their completion status in index.php.
    3. Test updating task status using update_task.php.
    4. Ensure deletion of tasks functions correctly with delete_task.php.

Chapter 8 Project: Multi-functional Library Management System

Project Overview: Develop a comprehensive Library Management System (LMS) that integrates various functionalities relevant to the topics covered throughout the course. The LMS will allow users to manage library resources, borrow and return books, search for books, and provide administrative functionalities.

Project Components:

  1. Computer architecture and processor optimization: Implement efficient data structures and algorithms for managing large datasets of books and user information. Optimise data retrieval and storage operations to minimize processing time using techniques such as indexing and caching.
  2. Object-Oriented Programming (C++, Java, Python): Choose one programming language (C++, Java, or Python) to implement the core functionalities of the LMS. Use object-oriented principles to design classes such as Book, User, Library, and Transaction to model the entities and interactions within the system.
  3. Computer networks: Implement network communication aspects such as client-server architecture for remote access to the LMS. Design protocols for data exchange between the client (library users) and server (library database).
  4. Operating systems: Consider concurrency and synchronization issues when implementing features like book borrowing and returning to ensure data consistency. Utilize file handling and memory management concepts for efficient data storage and retrieval.
  5. Databases and Database Management Systems: Design a relational database schema using SQLite, MySQL, or PostgreSQL to store information about books, users, transactions, etc. Implement CRUD (Create, Read, Update, Delete) operations to interact with the database from the LMS application.

Project Deliverables:

  1. Functional LMS application: A fully functional application with a user-friendly interface for library users (borrowers) and administrators (librarians).
  2. Documentation: Detailed documentation including system design, database schema, class diagrams, user manuals, and technical specifications.
  3. Presentation: A final presentation demonstrating the LMS functionalities, architecture, and optimisation strategies used.
